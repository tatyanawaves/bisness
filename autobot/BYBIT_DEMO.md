# Бот для Bybit Demo: запуск на своём компьютере

Бот торгует только на **демо-счёте Bybit** (виртуальные USDT). Из облака Claude он не
работает: Bybit блокирует регион облачного сервера, поэтому запускать его нужно у себя.

## Стратегия

- Раз в неделю (понедельник, по UTC) бот смотрит вчерашнее закрытие BTC/USDT.
- Цена выше средней за 100 дней: держит **лонг**. Ниже: держит **шорт**.
- Размер позиции: половина бюджета, по умолчанию 0.5 × 10 000 = 5 000 USDT, плечо 1.
- Если счёт потерял 2 500 USDT с момента старта, бот закрывает позицию и останавливается.

Проверка на истории (дневные цены, комиссия 0.1%, ставки финансирования не учтены):

| Период | Доход в год | Макс. просадка |
|---|---|---|
| 2021–2024 (на нём правило выбрано) | +13.9% | −31% |
| 2025–2026 (проверка) | +8.9% | −21% |

Правило меняет направление около 4 раз в год. Это не гарантия прибыли: из 44 проверенных
правил только треть была в плюсе на обоих периодах, и это одно из них.

## Установка

1. Установите Python 3.9+ (python.org). На Windows отметьте «Add Python to PATH».
2. Скачайте репозиторий: `git clone https://github.com/tatyanawaves/bisness` и перейдите в папку.
   Пока PR #4 не влит: `git checkout ccr-09243fdd-xh71s5`.
3. Установите библиотеку: `pip install ccxt`
4. Получите демо-ключи: на bybit.com наведите на профиль → **Demo Trading**, затем в
   демо-режиме профиль → **API** → создать ключ с правом торговли (Contract / Unified Trading).
5. Создайте файл `trader/bybit/.env` (папка `trader/` не попадает в git):

   ```
   BYBIT_DEMO_KEY=ваш_ключ
   BYBIT_DEMO_SECRET=ваш_секрет
   ```

   Ключи не отправляйте в чат.

## Запуск

```
python autobot/bybit_demo_bot.py            # пробный прогон: покажет, что сделал бы
python autobot/bybit_demo_bot.py --trade    # отправляет заявки на демо-счёт
python autobot/bybit_demo_bot.py --status   # позиция и результат
python autobot/bybit_demo_bot.py --close --trade   # закрыть позицию и остановить
```

Сначала запустите пробный прогон и пришлите его вывод, если что-то выглядит не так:
с настоящим Bybit бот ещё не проверялся, только на тестовой заглушке.

## Расписание

Боту достаточно одного запуска в день.

- **Windows:** Планировщик заданий → Создать простую задачу → Ежедневно, например 03:10 →
  Программа `python`, аргументы `autobot\bybit_demo_bot.py --trade`, рабочая папка — папка
  репозитория.
- **macOS / Linux:** `crontab -e` и строка
  `10 3 * * * cd /путь/к/bisness && python3 autobot/bybit_demo_bot.py --trade >> trader/bybit/cron.log 2>&1`

## Настройки и файлы

`trader/bybit/settings.json` (необязательно) меняет значения по умолчанию:

```json
{"budget": 10000, "size_fraction": 0.5, "sma_days": 100, "max_loss_usd": 2500}
```

- `trader/bybit/log.jsonl` — журнал всех действий.
- `trader/bybit/state.json` — с какого баланса бот стартовал.
- `trader/bybit/STOP` — пока файл есть, бот ничего не делает. Удалите его, чтобы запустить снова.

## Ограничения

- Только демо: бот включает демо-режим в коде и завершится, если адрес биржи не `api-demo`.
- Результат считается по всему демо-счёту, поэтому не торгуйте на нём вручную.
- Режим позиций на счёте должен быть односторонним (One-Way), это режим по умолчанию.
