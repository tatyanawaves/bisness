# Поиск клиентов

Помощник менеджера по холодным звонкам. Находит в выбранном городе Казахстана компании, которые регулярно что-то закупают, оценивает их и готовит скрипт для каждого звонка. Подходит для любого товара или услуги.

## Запуск

Команды выполняются из корня проекта `finvy-b2b-outreach`.

```bash
python -m venv .venv
```

```bash
.venv\Scripts\pip install -r requirements.txt
```

```bash
copy lead_finder\.env.example lead_finder\.env
```

Заполните ключи в `lead_finder/.env`, затем:

```bash
.venv\Scripts\python -m lead_finder.app
```

Приложение откроется по адресу http://127.0.0.1:5050.

## Ключи

| Переменная | Для чего | Где взять |
| --- | --- | --- |
| `GROQ_API_KEY` | Разбор вашей компании, анализ клиентов, подбор слов в скрипте | https://console.groq.com/keys, бесплатно |
| `GOOGLE_PLACES_API_KEY` | Поиск компаний с телефонами. Нужно включить Places API (New) и биллинг | https://console.cloud.google.com/apis/credentials |
| `DGIS_API_KEY` | Поиск через 2ГИС вместо Google | https://platform.2gis.ru |

Без `GROQ_API_KEY` приложение работает, но размер оценивается только по названию и числу филиалов, а скрипт собирается по шаблону уроков.

Без ключа карт поиск не запускается.

### Как получить ключ 2ГИС

1. Зарегистрируйтесь на https://platform.2gis.ru.
2. Создайте демо-ключ. Он создаётся один раз и действует месяц, лимит 1000 запросов.
3. Впишите ключ в `DGIS_API_KEY`, в `.env` оставьте `MAP_PROVIDER=2gis` и перезапустите приложение.

В демо-ключе нет телефонов: у каждой компании будет ссылка на её карточку в 2ГИС. Чтобы телефоны приходили сразу, а поиск работал после пробного месяца, нужна платная подписка и отдельное разрешение на контакты через отдел продаж.

### Как получить ключ Google Places

1. Откройте https://console.cloud.google.com и выберите или создайте проект.
2. Подключите к проекту платёжный аккаунт. Без него Places API не работает, даже в пределах бесплатного объёма: Google отвечает `The caller does not have permission`.
3. Включите **Places API (New)**: https://console.cloud.google.com/marketplace/product/google/places.googleapis.com
4. Создайте ключ: https://console.cloud.google.com/apis/credentials
5. В настройках ключа ограничьте его одним API, Places API (New).
6. Впишите ключ в `GOOGLE_PLACES_API_KEY` и перезапустите приложение.

Чтобы расход не вышел за ожидаемый, задайте лимит запросов в день на странице квот проекта.

### Что важно знать о картах

- **Google Places.** Запрос с телефонами считается по тарифу Text Search Enterprise: 1000 запросов в месяц бесплатно, дальше 35 долларов за 1000. Один запрос возвращает до 20 компаний.
- **2ГИС.** Демо-ключ бесплатный на месяц и на 1000 запросов, но телефоны (`contact_groups`) в него не входят: они подключаются за отдельную плату через отдел продаж. Без них приложение показывает компании и ссылку «Найти в 2ГИС».
- **Хранение данных.** Приложение сохраняет найденные компании в свою базу, чтобы хранить отметки, анализы и скрипты. И Google, и оферта 2ГИС ограничивают хранение данных из API. Перед коммерческим использованием уточните условия у поставщика данных.

### Лимиты Groq

По документации Groq для `openai/gpt-oss-120b`: 30 запросов в минуту, 1000 в день, 8000 токенов в минуту. Поэтому компании анализируются порциями по 6, а при коротком лимите приложение ждёт и повторяет запрос. Точные лимиты вашего ключа: https://console.groq.com/settings/limits. Если дневной лимит закончился, остальные компании оцениваются без ИИ, и интерфейс об этом сообщает.

## Как устроен скрипт

Шаги и формулировки закреплены в `playbook.py` по урокам «Андеграунд-продажи»:

1. Секретарь: кто → должность → имя → соединение → ответственный.
2. Первые 30 секунд: без презентации компании.
3. Регулярные позиции.
4. Актуальные заявки: позиция → параметр → объём → срок → место.
5. Текущий поставщик: всё ли устраивает, нужен ли дополнительный.
6. Предложение: сравнить цены или предположение из анализа, заданное вопросом.
7. Кто принимает решение.
8. Следующий шаг: причина → дата → действие.

Модель только подбирает слова под компанию и ваш товар: как спросить секретаря, какие характеристики уточнять, что предположить. Её ответы проверяются, и реплика с запрещённой уроками фразой заменяется стандартной.

## Где что лежит

- База SQLite: `lead_finder/data/leads.db`. Хранит компании, отметки об отработке, разборы вашей компании, все анализы и все версии скриптов.
- Отработанная компания не возвращается в поиск своего города, даже если придёт с другим идентификатором или из другого источника: сверяются название и телефон. Вернуть её можно в разделе «Отработанные».

Приложение рассчитано на локальный запуск и не имеет входа по паролю. На Render без постоянного диска база будет обнуляться при каждом деплое, а без авторизации ваши ключи карт сможет расходовать любой посетитель.
